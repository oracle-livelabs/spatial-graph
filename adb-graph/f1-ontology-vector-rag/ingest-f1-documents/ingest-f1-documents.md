# Load and Chunk the F1 Documents

## Introduction

In this lab, you store two F1 PDFs in the database and split their text into overlapping chunks. A chunk is a short, focused input for the language model in the next lab. Each chunk keeps the ID of its source document, so you can trace every fact back to its source.

Estimated Time: 8 minutes

### Objectives

In this lab, you will:

- Open SQL Worksheet as the lab user.
- Create tables for documents and chunks.
- Load two PDFs from Object Storage.
- Split the text into overlapping chunks and check the result.

## Task 2: Create the document tables

1. Create one table for the PDFs and one for the chunks. Paste the block and click **Run Script** (F5).

    ```sql
    <copy>
    CREATE TABLE IF NOT EXISTS f1_documents (
      document_id   NUMBER GENERATED BY DEFAULT AS IDENTITY
                    CONSTRAINT f1_documents_pk PRIMARY KEY,
      document_name VARCHAR2(255) NOT NULL,
      document_blob BLOB          NOT NULL,
      loaded_at     TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL
    );

    CREATE TABLE IF NOT EXISTS f1_document_chunks (
      document_id NUMBER NOT NULL,
      chunk_id    NUMBER NOT NULL,
      chunk_text  CLOB   NOT NULL,
      CONSTRAINT f1_document_chunks_pk PRIMARY KEY (document_id, chunk_id),
      CONSTRAINT f1_document_chunks_doc_fk
        FOREIGN KEY (document_id) REFERENCES f1_documents (document_id)
    );
    </copy>
    ```

    Chunk numbers restart at 1 for each document, so a chunk is identified by the pair `(document_id, chunk_id)`.

    ![Document tables created](./../../ingest-f1-documents/images/02-create-tables-highlighted-1280.png)

## Task 3: Load the two PDFs

1. Copy the two read-only document URLs:

    - Beginner's guide: [](var:f1_guide_pdf_url)
    - Expanded 2026 article: [](var:f1_article_pdf_url)

2. Replace the two placeholders in the block below with those URLs, then run it with **Run Script**. `DBMS_CLOUD.GET_OBJECT` downloads each file straight into a BLOB column. The `NOT EXISTS` check makes the block safe to run again.

    ```sql
    <copy>
    INSERT INTO f1_documents (document_name, document_blob)
    SELECT 'f1rules.pdf',
           DBMS_CLOUD.GET_OBJECT(credential_name => NULL,
                                 object_uri      => '<beginners-guide-url>')
    FROM dual
    WHERE NOT EXISTS (SELECT 1 FROM f1_documents WHERE document_name = 'f1rules.pdf');

    INSERT INTO f1_documents (document_name, document_blob)
    SELECT 'f1text.pdf',
           DBMS_CLOUD.GET_OBJECT(credential_name => NULL,
                                 object_uri      => '<expanded-article-url>')
    FROM dual
    WHERE NOT EXISTS (SELECT 1 FROM f1_documents WHERE document_name = 'f1text.pdf');

    COMMIT;
    </copy>
    ```

    ![Two PDFs loaded, URLs blurred](./../../ingest-f1-documents/images/03-load-pdfs-highlighted-1280.png)

## Task 4: Extract text and create chunks

1. Preview the first 500 characters of text from each PDF. `DBMS_VECTOR_CHAIN.UTL_TO_TEXT` reads the PDF format inside the database.

    ```sql
    <copy>
    SELECT document_name,
           DBMS_LOB.SUBSTR(DBMS_VECTOR_CHAIN.UTL_TO_TEXT(document_blob), 500, 1) AS text_preview
    FROM f1_documents;
    </copy>
    ```

    ![Text preview of each PDF](./../../ingest-f1-documents/images/05-text-preview-highlighted-1280.png)

2. Split every document into chunks of up to 750 characters. The 150-character overlap keeps a sentence that crosses a boundary whole in at least one chunk.

    ```sql
    <copy>
    INSERT INTO f1_document_chunks (document_id, chunk_id, chunk_text)
    SELECT d.document_id,
           JSON_VALUE(c.column_value, '$.chunk_id'   RETURNING NUMBER),
           JSON_VALUE(c.column_value, '$.chunk_data' RETURNING CLOB)
    FROM f1_documents d
    CROSS JOIN TABLE(
      DBMS_VECTOR_CHAIN.UTL_TO_CHUNKS(
        DBMS_VECTOR_CHAIN.UTL_TO_TEXT(d.document_blob),
        JSON('{"by":"chars","max":"750","overlap":"150",
               "split":"recursively","language":"english","normalize":"all"}')
      )
    ) c
    WHERE NOT EXISTS (SELECT 1 FROM f1_document_chunks x
                      WHERE x.document_id = d.document_id);

    COMMIT;
    </copy>
    ```

    `UTL_TO_CHUNKS` returns a collection of JSON chunks. `TABLE(...)` turns that collection into rows, and `CROSS JOIN` repeats this for each document.

    ![Chunks inserted](./../../ingest-f1-documents/images/06-create-chunks-highlighted-1280.png)

3. Count the chunks per document.

    ```sql
    <copy>
    SELECT d.document_name, COUNT(*) AS chunk_count
    FROM f1_documents d
    JOIN f1_document_chunks c ON c.document_id = d.document_id
    GROUP BY d.document_name
    ORDER BY d.document_name;
    </copy>
    ```

    Expect about 30 chunks in total. The next lab sends each chunk to the language model once.

    ![Chunk count per document](./../../ingest-f1-documents/images/07-chunk-count-highlighted-1280.png)
